# 侧栏 / 抽屉视觉改造任务单（2026-11-01）

> 分支：`feat/sidebar-visual`（从 beta `5f2a396f` 切出）。
> 依据：`/home/ubuntu/aa-test/sbx-re-harvest/reports/DRAWER-VISUAL-PARAMS.md`（E = 二进制闭合，R = 官方截图像素测量）。
> 原则：只改视觉参数，不动交互、动画时序与数据逻辑；每项偏差可单独回退。

## 0. 目标

把 AA 会话侧栏与抽屉的视觉参数对齐官方 Claude iOS（v261023 逆向 + 两张官方截图），使打开态、行列表、底部工具条、阴影观感与官方一致。

## 1. 证据基线（详见参数汇总文档）

**E（二进制）**

- 抽屉宽 = `min(320pt, 0.85 × 容器宽)`；位移量化 `pixelLength × rint(offset / pixelLength)`。
- 卡片阴影：black / offset (0,0) / radius 6 / opacity 0.1。
- 侧栏阴影（drawerShadow）：black / offset (0,0) / radius 12 / opacity 0.16；shadowPath `CGRectInset(bounds, 0, -24)`。
- 左缘 1px 界线 ≈ rgb(205,205,202)。
- 令牌：Spacing `{0,2,4,8,12,16,20,24}`、CornerRadius `{0,8,10,14,16,20,24}`、Elevation 四档（`.05,2,1` / `.10,2,2` / `.08,4,2` / `.10,7.5,10`）。
- 侧栏字号：直连预设 15pt / weight 400 / 行高 21；其它预设 17/550+700、17/400+600、15/550+700、13/400、13/550+700、11/400。

**R（截图，iPhone 1179×2556@3x，pt = px/3）**

- 行距 50、行高/选中高 48、选中内缩 12、选中圆角 ≈14、选中填充 `#E7E6E1`。
- 图标 18、图标左边距 27、图标-文字间距 16、文本左缘 60.7、行文本 ≈17pt。
- 表面：侧栏底 `#F3F3F0`、卡片底 `#F9F9F7`、主文字 `#131313`、次文字 `#52514E`。
- New Chat pill：110.3×46.7、capsule r≈23.3、底 `#2B2B28`、白字、距底 28.7。
- 头像 48 / 左边距 28 / 底距 28；标题左边距 20.3；搜索按钮 44。
- 打开态卡片左缘 320pt（侧栏可见 81.4% 屏宽）；半开图仅用于对照左缘阴影衰减（≈10.7pt + 1px 界线）。

## 2. 范围（Phase 1，本单）

1. **抽屉几何与阴影**（`SidebarDrawer.swift`）
   - reveal：`0.75 × 屏宽` → `min(320pt, 0.85 × 屏宽)`。
   - 卡片阴影：radius 18 / opacity 0.28 → **radius 6 / opacity 0.1 / offset (0,0) / black**。
   - 新增侧栏后方的 drawerShadow 层：**radius 12 / opacity 0.16**，shadowPath 上下外扩 24pt。
   - 卡片左缘描边：改为 **1px ≈ rgb(205,205,202)**。
2. **侧栏列表**（`ChatSidebarView.swift` 及行视图）
   - 行高 48、行距 50（由 `LazyVStack(spacing: 6)` + 自适应行改为固定行高/间距）。
   - 选中高亮：左右内缩 12、高 48、圆角 14、填充 `#E7E6E1`。
   - 图标 18、图标左边距 27、图标-文字间距 16、文本左缘 60.7。
3. **底部工具条**：pill 110.3×46.7 / capsule / `#2B2B28` / 白字 / 底距 28.7；头像 48 / 左 28 / 底 28。
4. **顶栏**：标题左边距 20.3；搜索按钮 44。
5. **表面与文字色**：侧栏底 `#F3F3F0`、卡片底 `#F9F9F7`、主文字 `#131313`、次文字 `#52514E`。
6. **字号**：行标题 17pt（R）或 15pt（E，直连预设）二选一真机对照；辅助文字 13/15；标题 Serif 先按 22pt（E 预设）对照 24pt（R）后定。

## 3. 本单不做

- 不改抽屉手势参数与动画时长（12pt/35°/60pt/s、response 0.2 / damping 1.0 保持）。
- 不改时间线引擎、列表窗口、滚动逻辑。
- 不做颜色令牌化与动态色反转（Phase 2；当前直接用 R 色值）。
- 不动 120Hz 保活与探针。

## 4. 验收

- 真机对照：打开态卡片左缘 **320pt**；行距 50 / 选中高 48 / r14 / `#E7E6E1`；pill 与头像几何一致；半开时左缘阴影观感一致。
- 出 probe 包（tag `ipa-feat-sidebar-visual`）+ 真机截图对照；偏差项标 U 回报。
- 回归：抽屉 120Hz 帧率与起始帧指标不劣化（同一探针口径）。

## 5. 风险与 U

- 新增侧栏阴影层可能影响抽屉动画逐帧成本 → 出包后用探针复测 `period/avgGap/first`。
- 固定行高/间距需检查滚动、选中态命中与 Dynamic Type。
- 行字号 15 vs 17、标题 22 vs 24 未闭合。
- 颜色 token 名字未闭合（Phase 2）；截图为 16-bit P3 近似，sRGB 下可能 ±1–2 级。
- 侧栏压暗机制、pill 横向定位基准仍 U，不影响本单几何。

## 6. 交付顺序

1. 抽屉几何 + 卡片/侧栏阴影 + 左缘描边
2. 列表行高/间距/选中态
3. 底部工具条与顶栏
4. 表面/文字色值
5. 出包真机对照（必要时按反馈微调字号）
